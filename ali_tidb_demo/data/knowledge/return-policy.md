# Demo 企业退换货政策

本文是 AI Agent 演示语料，不代表任何真实企业的售后承诺。

客户在商品签收后的 7 个自然日内，可以申请无理由退货。申请时商品应保持完好，不影响二次销售，并随附原包装、配件和购买凭证。超过 7 个自然日的申请，需要先由售后人员检查，不能直接承诺退款。

定制商品、已经激活的软件许可，以及因客户不当使用造成损坏的商品，不适用无理由退货。若商品本身存在质量问题，应单独创建售后工单，由售后人员依据检测结果处理。

退货申请通过后，系统生成退货编号。仓库验收商品后，退款原路退回。演示流程中的退款处理时限为 3 个工作日；实际企业流程应以正式制度和支付渠道规则为准。
